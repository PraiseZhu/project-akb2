## §2 Mac Mini 待验证清单

部署后在 mac mini 上执行以下命令验证端到端链路。请先替换 `__AKB2_REPO_ROOT__` 为实际仓库路径。

### SC-7-real（真实 iCloud vault 写入）
```bash
# 运行一次完整 pipeline（当天日期自动推算为明日 briefing）:
bash scripts/daily_briefing.sh \
  --vault-root "/Users/praise/Library/Mobile Documents/iCloud~md~obsidian/Documents" \
  --date $(TZ=Asia/Shanghai date +%Y-%m-%d)

# 验证文件写入（次日日期）:
TOMORROW=$(TZ=Asia/Shanghai date -v+1d +%Y-%m-%d)
test -f "/Users/praise/Library/Mobile Documents/iCloud~md~obsidian/Documents/AKB2.0/AI TRENDS/Social/${TOMORROW} Daily Briefing.md" && echo OK
```

### SC-8-launchctl（launchd 注册 + 触发时间验证）
```bash
# 1. 替换占位符并安装 plist
AKB2_REPO=/path/to/akb2-repo   # 替换为实际路径
sed "s|__AKB2_REPO_ROOT__|${AKB2_REPO}|g" \
  "${AKB2_REPO}/launchd/com.akb2.briefing.plist" \
  > ~/Library/LaunchAgents/com.akb2.briefing.plist

# 2. 加载 LaunchAgent
launchctl load ~/Library/LaunchAgents/com.akb2.briefing.plist

# 3. 验证已注册
launchctl list | grep com.akb2.briefing

# 4. 验证下次触发时间 ≤ 24h（预期 07:30 Asia/Shanghai）
next=$(launchctl print gui/$(id -u)/com.akb2.briefing | awk -F'= ' '/next fire date/{print $2}')
echo "next fire date: $next"
now_epoch=$(date +%s)
next_epoch=$(date -j -f "%Y-%m-%d %H:%M:%S %z" "$next" +%s 2>/dev/null || date -d "$next" +%s)
diff=$((next_epoch - now_epoch))
[ $diff -le 86400 ] && [ $diff -gt 0 ] && echo "OK: fires in ${diff}s" || echo "WARN: unexpected fire time"
```

## §4 残余风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| X API 不可用（无 X_BEARER_TOKEN） | 真实抓取失败，collectors 返回空 | dry-run-intake 模式使用 fixture 数据；mac mini 部署需配置真实 bearer token |
| DeepSeek API 不可用（无 OPENROUTER_API_KEY） | synthesis 使用 fallback 路径，语义质量降低 | schema 合规保留；fallback 输出通过 validator；需在 mac mini 上配置真实 key |
| Gate HC-11/12 反填表校验 MVP 范围外 | 简报内容语义质量未深度校验，可能有高置信但低质量条目进 active | 归后续 Plan（7天后）；当前阶段靠人工 Obsidian 审阅 |
| self-evolving 权重升降级未实现 | scoring 阈值固定 0.7，无动态调整 | 归 7 天后 Plan；当前 fixture 全部通过阈值，风险低 |
| mac mini 时区必须为 Asia/Shanghai | plist Hour=7 Minute=30 在错误时区会导致触发时间偏移 | SC-8-launchctl 验证 next fire date；部署前检查 mac mini 时区设置 |
| vault-stub 与真实 vault 路径差异 | 本机测试用 fixture，mac mini 需真实路径 | docs/mac-mini-deployment-notes.md 已记录路径替换步骤 |
